# Security policy

## Reporting a vulnerability

Please report it privately: on the repository page open the **Security** tab and choose **Report a vulnerability**. Do not open a public issue for it.

Include what you found, the file or script involved, and the steps to reproduce it. A report that shows a script writing outside the project folder (other than publish `repo` mode, which does so by design), running an unlisted command, or leaking private data from a register is in scope.

## Supported versions

Only the latest release gets fixes. Stability promises are in the Limits section of `README.md`.

## What the skill does

`PRIVACY.md` lists what the skill reads and writes. `skills/pmo-docs/SKILL.md` (Safety rules) lists what the agent must never do.
