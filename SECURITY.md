# Security policy

## Reporting a vulnerability

Please report it privately: on the repository page open the **Security** tab and choose **Report a vulnerability**. Do not open a public issue for it.

Include what you found, the file or script involved, and the steps to reproduce it. A report that shows a script writing outside the project folder, running an unlisted command, or leaking private data from a register is in scope.

## Supported versions

Only the latest release gets fixes. The skill is pre-1.0, so a fix can change a config key or register format.

## What the skill does

`PRIVACY.md` lists what the skill reads and writes. `skills/pmo-docs/SKILL.md` (Safety rules) lists what the agent must never do.
