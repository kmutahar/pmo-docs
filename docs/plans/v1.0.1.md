# 1.0.1: verification release

Status: planned. Decided with the maintainer on 2026-11-11 (UTC). Hub and settled decisions: [`docs/PLAN.md`](../PLAN.md). Agent rules and the release checklist: hub section 8.

---

## 1. Scope

The checks that use the most usage run once, after 1.0.0, for every version up to it (decided 2026-11-11, UTC). Nothing is built here except fixes for what the checks find.

**In**

- The hub's deferred checks (section 8), on the 1.0.0 tree: SkillSpector, every eval, the walkthrough check, the install check, one Opus review at high effort.
- Fixes for findings, each with a test or an eval change.

**Out**

- New features. A fix that changes a config key or a register format is a breaking change and waits for 2.0.

## 2. Packages

| Package | Size | Model | Commit subject |
|---|---|---|---|
| W1 Checks and fixes: run each deferred check, analyse a failure as a grader fault or a skill fault before any `SKILL.md` change, fix, run again | M | Sonnet high; Opus high for the review | one subject per fix |
| W2 Release | S | maintainer + Sonnet | `chore(release): v1.0.1` (`v1.1.0` if a fix changes behaviour; written by `dev/release`) |

**Done when:** SkillSpector is SAFE with full coverage; every eval passes (`translation-parity` and `intake-consent` twice); the walkthrough and install checks pass; the Opus review has no open finding; the suite and scrub pass.
