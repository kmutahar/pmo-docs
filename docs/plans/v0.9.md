# 0.9: verification

Status: planned. Decided with the maintainer on 2026-11-11 (UTC); moved ahead of the first major release the same day so that a finding can still change a format. Hub and settled decisions: [`docs/PLAN.md`](../PLAN.md). Agent rules and the release checklist: hub section 8.

## 1. Scope

The checks that use the most usage run once, on the tree that the first major release will ship, for every version up to it (decided 2026-11-11, UTC). Nothing is built here except fixes for what the checks find.

**In**

- The hub's deferred checks (section 8): SkillSpector, every eval, the walkthrough check, the install check, one Opus review at high effort.
- Fixes for findings, each with a test or an eval change. A finding too big for this version (a redesign, not a fix) is not forced in: it gets its own extra release before the final one, with its own plan file, and the checks it touches run again there.
- The icon under 256 KiB (`dev/icon.svg` is the master), so the tree meets the directory's file limit. Check first whether a binary icon is allowed.

**Out**

- New features. A fix may change a config key or a register format (nothing is stable until the first major release), but it needs the maintainer's yes and a note in that release's text.
